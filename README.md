# Ho`ike - The Hawaiian Fish Species Mobile Classifier

## Overview
<b>A cross-platform mobile application that identifies Hawaiian fish species from a photo using machine learning</b>

### Features
- Identiy Hawaiian fish from just a photo
- Species information database
- Works both online and offline
- Andriod and IOS support

### Project Goal
<b>The goal of this project is to help:</b>
- Recreational fishermen identify their catches
- Make fishing regulation more convient
-
